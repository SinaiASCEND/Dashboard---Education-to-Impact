# From Education to Impact (Strategic Plan, public site)

Public ASCEND dashboard for the MD Program Strategic Plan 2026–2031: the plan and its key performance
indicators, the roadmap and milestones for the Year 1 initiatives G2.2 Curriculum Content Gap Closure and
G3.1 Emerging Healthcare Competency Framework, the Year 1 teams and the G2.2 gap register.

- Hosting: GitHub Pages from `main` (public). Open it from the ASCEND Hub.
- Working files stay in SharePoint: the draft charters, the gap report, Steering Committee materials and a
  working details workbook (members, actions, meetings, minutes, materials). The Working files tab links them
  with "People in Mount Sinai can view" links, so they open only with a Mount Sinai sign-in.
- Data: `data/e2i-data.js` is generated by `python3 tools/build.py` from the OneDrive master folder
  `# Dashboards/22 Strategic Plan/2 MASTER - Claude only/` (`e2i-data.json` + `links.json`). Only gaps,
  milestones and the SharePoint links reach this site; the build stops if an email address gets through.
  The same run rewrites the working details workbook and the gap report PDF in place in the master's
  `files/` folder, so their SharePoint links keep working.
- Update: edit the master, run the build, open a PR. Pages republishes about a minute after the merge.

The previous code-gated version lives in the private repo `Dashboard---Strategic-Plan`.
